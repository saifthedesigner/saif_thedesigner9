# Saif Ismail Portfolio — GitHub Pages ready

## Upload to GitHub Pages

**Important:** `index.html` must be in the repository root, next to the `assets` folder. Do not upload the outer project folder as a nested folder.

1. Open your repository: https://github.com/saifthedesigner/saif_thedesigner6
2. Choose **Add file → Upload files**.
3. Open this ZIP on your computer and enter the `saif-ismail-portfolio` folder.
4. Upload **everything inside that folder**: `index.html`, `README.md`, `.nojekyll`, and the complete `assets` folder.
5. Commit the changes to the branch/folder configured for GitHub Pages (usually `main` and `/(root)`).
6. Wait for the Pages deployment to finish, then open:
   https://saifthedesigner.github.io/saif_thedesigner6/
7. Hard refresh with **Ctrl + F5**.

## Image files

The HTML and JavaScript use relative paths such as `./assets/images/portrait.jpg`.
Keep the `assets/images` folder and all filenames unchanged, including capitalization.

The page includes inline CSS and JavaScript. The separate `assets/css/style.css` and `assets/js/main.js` files are retained, but the current `index.html` contains its own styles and scripts.
